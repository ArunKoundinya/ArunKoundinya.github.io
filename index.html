py-flow-mapper

A beta Python package that turns a codebase into Mermaid flow diagrams using static AST analysis. It shows which functions call which and how return values flow between them, without running the code or depending on an LLM.

# map any project in two commands
$ pip install py-flow-mapper
$ pyflow analyze ./my_project
$ pyflow diagram project_meta.json

LLM persona enginePrivate · live

Sthayi

An experiment in characters that change over time. Most chatbots treat a persona as a fixed prompt. In Sthayi, the relationship writes to a state, and that state shapes how the character speaks each turn: register, directness and willingness to push back. It has seven memory threads and group conversations, and is now in a month of daily use to see whether week four feels different from week one.

  • Next.js
  • Supabase Postgres
  • Embeddings
  • LLM APIs
  • Vercel
